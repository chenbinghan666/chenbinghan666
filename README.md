## 代表作品

### [Desktop Agenda](https://github.com/chenbinghan666/desktop-agenda/blob/main/README.md)

把 Google 日历放在 Windows 桌面上。日、周、月和列表四种视图方便随时查看课表、会议和截止日期。日程通过 iCal 只读同步。

C# · WPF · Google Calendar · [下载桌面日历](https://github.com/chenbinghan666/desktop-agenda/releases/latest)

### [CALVIN Failure Analysis](https://github.com/chenbinghan666/calvin-failure-analysis/blob/main/README.md)

当机器人五步任务全部失败时，怎样定位它从哪一步开始出错？用 CALVIN 仿真和 MCIL 公开模型逐步检查动作偏差，并记录重试能否恢复。仓库附实验图表、数据和中文报告。

Python · CALVIN · MCIL · [查看实验报告](https://github.com/chenbinghan666/calvin-failure-analysis/blob/main/docs/report.pdf)

## Windows 与自动化

- [**PUBG AFK Helper**](https://github.com/chenbinghan666/pubg-afk-helper/blob/main/README.md) · 用 OpenCV 识别 PUBG 界面，在 Windows 上展示识别状态并执行可配置流程。提供只识别的预览模式和离线回归测试。
- [**Daily Mail Report Bot**](https://github.com/chenbinghan666/mail_digest_bot/blob/main/README.md) · 把示例邮件按发件人汇总，再通过 Telegram 发送每日报告。这是我的第一个公开 Python 练习项目，适合从报告生成与消息发送两个模块读起。

## AI 与文献检索

- [**Drug–Gene RAG**](https://github.com/chenbinghan666/drug-gene-rag/blob/main/README.md) · 输入基因、药物和癌症类型，从 PubMed 检索摘要，再用智谱模型整理文献中的关联证据。面向学习和文献辅助阅读。
